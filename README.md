# RunPad

Interactive terminal interface for discovering and running scripts from
`package.json`.

## Installation

**npm**

```bash
npm install -g @heleg/runpad
```

**mise**

```bash
mise use npm:@heleg/runpad
```

## Usage

Run from your project directory:

```bash
rp
```

Or:

```bash
runpad
```

## Requirements

Node.js >= 22.18.0
